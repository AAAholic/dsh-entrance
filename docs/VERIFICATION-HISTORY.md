# 历史验证范围与当前发布的关系

本文核对的是 2026-10-06 及之前的开发记录。它用于说明实现经验的证据来源，不是本独立插件的发布验收报告。独立包使用自己的构建、测试、真实宿主 boot 与浏览器检查；原有 `whale-girl` 增强版的原生桌面观察单独记录，不能替代独立包的原生验收。

原性能报告中存在早期退出实现的“工作台先释放、尾波后消失”时长，后来已经被共享水波遮罩取代。因此这里只引用像素预算和明确标注环境的性能观察，不把早期退出时长当成现行契约。

原始验证文件还包括绝对路径、进程信息、截图和备份位置；这些私人工程资料没有复制到独立公开仓库。本文保留原记录的相对名称便于作者追溯，并将适合公开复用的机制写进其他文档。

## 从代码可以确认、仍需要运行验证的契约

| 契约 | 应如何核验 |
| --- | --- |
| 主入场结束后停止其 RAF | 等待 settled 后统计主时钟，区分仍运行的局部鱼群/飘带 |
| 默认处于新强度范围的中点 | 比较迁移前默认与迁移后 50% 的实际参数和画面；再验证 0%、100% |
| 手部幅度、速度与飘带幅度、速度各自独立 | 单独改变一个参数，检查另一个不被隐式重设；极值无裂缝/裁切 |
| 多条鱼连续错峰弧线跃水且不完全相同 | 跨一个完整周期检查可见数量、轮廓、大小、配色、弧线、出入水与遮挡，不用单帧对象数量代替可见数量 |
| 退出手势不会传入工作台 | 长按超过视觉退出时长，再释放；键盘多键、重复、松开均检查 |
| 减少动态与后台清理 | loading、preparing、entering、settled、revealing 各阶段分别切换 |
| 失败不会卡住工作台 | 主人物失败、表情失败、装饰失败、超时、Canvas 不可用分别检查 |
| 独立安装 | 干净宿主中仅启用独立插件，检查资源路由、设置、卸载，不依赖原皮肤 |
| 宿主依赖注入 | 经真实 DSH boot 加载 `lib/client.js`，验证 `slots` 服务、设置分区与资源路由；独立 preview 直接导入 controller 无法覆盖此项 |
| 公开文件没有私人资料 | 检查包与 Git 索引实际清单，扫描绝对路径、凭据格式、私有截图和状态文件 |

## 本仓库的验证入口

- `npm test`：资源路径与服务、偏好迁移、游鱼等可独立检查的逻辑。
- `npm run check`：预构建客户端是否与当前源码一致。
- `npm run test:browser`：启动受限本地预览服务，使用实际素材检查控制器、设置、退出、输入保护、焦点和窄屏，写入 `test-results/browser-report.json`。
- 真实 DSH boot 加浏览器加载：补足 ModuleLoader、Cordis 注入、宿主插槽和服务挂载；不能用直接导入 controller 的预览代替。
- 原生 Electron 桌面：独立的观察层。没有相应包和版本的明确记录，就不声称它已通过原生验收。

2026-10-06 独立包最新结果为 Node 测试 `16/16`、实际浏览器 `20/20`、真实 boot 的 bundle 兼容/patch 检查通过、官方 Cordis `4.0.4` 生命周期 `2/2`。这里的生命周期检查包含依赖缺失、注入/移除/恢复、fiber 停用、路由重启无残留；其客户端 DOM/React 是测试替身，真实渲染由浏览器检查覆盖。

鱼群轨迹改变后的新检查替代之前 18 项独立浏览器结果；历史数字保留其原范围。上述检查未将独立 bundle 宣称为已通过原生桌面视觉验收。原有 `whale-girl` 增强版的原生观察属于另一安装对象。

## 当前仍应保留的限制

- 没有跨操作系统、不同 GPU、全部 DSH 版本的保证；宿主 API 变化需单独验证。
- 图片解码完成不等于所有 GPU 合成工作已经完成，首次运行与重播要分别观察。
- 历史黑块问题有明确的旧透明合成机制证据，但不能声称所有原生间歇闪烁已永久排除。
- 示例人物的裁切、枢轴和表情位置依赖特定画布与姿势，换角色需要重新调整。
- 技术检查通过与用户审美接受分别记录。
