# 水波退出：让波前真正擦除欢迎画面

关键不是在画面淡出后播放一段水纹，而是让水纹的位置决定欢迎画面哪里还可见。水体和遮罩消费同一个时钟、同一个原点、同一个波前几何函数。

## 一份几何数据驱动两个输出

点击退出时，把指针位置转换为欢迎容器内的归一化坐标；键盘退出使用中心 `(0.5, 0.5)`。归一化原点在窗口缩放后仍保持相对位置。

```js
p = clamp(exitElapsed / 2200, 0, 1)
waves = welcomeWaterWaves(p, width, height, origin)
```

对第 `i` 道波，`i = 0, 1, 2`：

```text
start = 0.10 + i × 0.13
u = clamp((p − start) / (1 − start), 0, 1)
radius = (1 − (1 − u)^1.25) × (reach + shortest × 0.075)
thickness = (shortest × 0.027 + 7) × (1 − 0.32u)
```

`reach` 是原点到最远角的距离，因此从角落点击也能覆盖整个画面。额外的短边余量使边缘被完整扫过。

Canvas 用这些半径和厚度画低透明度水体与局部高光；欢迎层用同一数据构造径向透明遮罩。水体的轮廓叠加少量不同频率的角度扰动，避免像机械同心圆。

## 逐波降低局部可见度

波前未经过的区域保持原图。第一、第二、第三道波经过后，该区域的剩余可见比例依次为：

```text
100% → 56% → 20% → 0%
```

遮罩沿各波前羽化，羽化宽度不能超过相邻波间距，否则颜色停靠点相互穿越。整张欢迎层的 `opacity` 保持 `1`，不再额外安排一个整图淡出。

这是水波与画面关联的原因：画面每一处消失的时刻由扩散半径决定，角色、文案、烟花和装饰一起参与消解。

## 同步露出真实工作台

对真实宿主 `#root` 使用 Web Animations API，从 `translate: 0 22px` 回到 `0 0`，时长同为 `2200 ms`。避免在揭幕同时给整个工作台做动态模糊。

这一动画只持有自身的 `Animation` 对象。结束、重播、卸载或中断时 `cancel()`，不覆盖宿主长期样式。宿主节点缺失或包含欢迎层时，跳过浮起，不影响水波完成。

## 视觉结束不等于输入已经安全

在捕获阶段消费用于退出的 `pointerdown`、`pointerup`、`click` 与按键事件。若用户按住鼠标超过 `2.2` 秒，视觉结束后仍要保留输入屏障，直到手势释放，并吞掉释放产生的那次 click。

同理，按住某个键退出后，其重复 `keydown` 和最终 `keyup` 不能落进工作台输入框。用独立集合记录已经消费的 pointer ID 和键码；页面失焦或进入后台时清理中断的输入状态。

退出前保存焦点；若触发按钮在 Shadow DOM 中，递归读取 `shadowRoot.activeElement`，不能只保存 `document.activeElement` 返回的 host。退出后仅在原节点仍存在、且没有抢走其他合理焦点时恢复。重播时，新场景重新获得具有可访问名称的 dialog 焦点。设置面板已经隐藏时，不再重复执行其旧焦点恢复。

## 资源与性能

水纹 Canvas 初始是 `1 × 1`，第一个有效退出帧才分配缓冲。像素比上限为 `1`，缓冲不超过约 `1,200,000` 像素。尺寸变化由 `ResizeObserver` 缓存，帧循环不读取布局。

预算表达的是内存和填充工作上限，不是跨设备的帧率保证。后台、减少动态、卸载、退出中重播都必须有立即清理路径。

## 复用时的最小检查

检查中心和四角退出、退场中缩放、长按鼠标、多键重复、退场中重播、退出中切后台、减少动态即时开启，以及 `#root` 缺失/嵌套两种情况。每次都确认最终无欢迎节点、无残留遮罩、无工作台临时动画、下一次正常点击可用。
