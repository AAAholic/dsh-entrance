# DSH Entrance v1.0.2

右上角原来的两个按钮合并为低对比度的“动画设置”胶囊入口，“重播动画”放在面板内。保留键盘操作、退出防穿透和焦点恢复，并检查窄窗中的设置与重播可达性。对应 [Issue #1](https://github.com/AAAholic/dsh-entrance/issues/1) 的入口干扰反馈。

默认安装继续使用随包宵宫作品。README 将演示与三步安装前置；只有用户主动要求个性化创作才进入 DIY。创作指引删除容易被当成默认偏好的具体角色示范，允许有依据的场景与配角联想，按实际画面判断完成度。三轮 DS 试用分别记录，第三轮明确为视觉不通过；修订后的创作能力仍标为实验性。

修复 CI 的 Ubuntu Azure HTTP 镜像下载停滞：使用官方 HTTPS 源，限制 APT 等待与重试，分开安装系统依赖和 Chromium headless shell，以独立步骤超时定位网络问题。新增根目录 CHANGELOG 并随安装包提供。

## 验证

本地构建一致性、Node 16/16、Chrome 浏览器 35/35 检查通过。安装包检查覆盖实际文件内容和 5 份素材校验值；本页发布附件来自下方链接的同一次成功 CI。详细环境、源码哈希及本机既有 whale-girl 同步观察见 [验证记录](https://github.com/AAAholic/dsh-entrance/blob/v1.0.2/docs/validation-1.0.2.json)。本机增强版的观察不代表独立安装包已通过原生 Electron 的完整性能验收。

宵宫素材和演示 GIF 本轮保持原样，未将未复现的重影问题或素材体积问题写成已解决。

## 安装

下载本页的 `dsh-entrance-1.0.2.tgz`，在 DSH 插件管理页选择“添加插件”，填入文件绝对路径或附件的直接下载地址。`SHA256SUMS` 提供安装包校验值。

代码与代码文档采用 MIT；示例 PNG 和演示 GIF 的权利范围见 LICENSE-ASSETS 和 NOTICE.md。DIY 使用完整 Git 克隆，运行安装包不包含开发脚本和根目录 SKILL。
