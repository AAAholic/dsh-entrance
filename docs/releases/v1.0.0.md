# DSH Entrance v1.0.0

首个带自动验证与安装包的正式版本：分层登场、人物问候、错峰跃鱼、随风飘带，以及交互水波退出。

- 提供独立 DSH 插件、预构建客户端和可运行本地示例。
- 附通用创作流程、素材准备原则、模板替换教程与实现复盘。
- CI 检查客户端构建一致性、Node 测试、Chromium 浏览器行为和实际安装包内容。

## 安装

下载本页的 `dsh-entrance-1.0.0.tgz`。在 DSH 插件管理页选择“添加插件”，填入该文件的绝对路径，安装后启用 `dsh-entrance`。也可填写本页安装包的直接下载地址。

`SHA256SUMS` 提供安装包校验值。GitHub 自动生成的 Source code 压缩包是仓库快照，`.tgz` 是本次 CI 验证过的安装包。
