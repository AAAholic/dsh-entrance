# DSH Entrance v1.0.1

修复首次发版过程中发现的自动发布问题：用 Git ref 判断标签是否存在，并按 Release ID 读取草稿，完成附件校验后再公开发布。

CI 继续检查构建一致性、单元测试、Chromium 浏览器行为和安装包内容；发布附件来自同一次成功验证。动画、示例素材与通用创作流程沿用 v1.0.0。

## 安装

下载本页的 `dsh-entrance-1.0.1.tgz`，在 DSH 插件管理页选择“添加插件”，填入文件绝对路径或附件的直接下载地址。`SHA256SUMS` 提供安装包校验值。

这是非官方社区插件。代码与代码文档采用 MIT；示例 PNG 和演示 GIF 的权利范围见 LICENSE-ASSETS 和 NOTICE.md。
