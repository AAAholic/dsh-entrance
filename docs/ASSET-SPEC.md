# 素材规格：准备自己的图片

先确定画面怎么摆，再准备图片。人物和表情需要彼此对齐；独立装饰按显示大小准备，不需要都做成同一个尺寸。

| 素材 | 关键原则 | 本模板的例子 |
| --- | --- | --- |
| 人物 | 保留完整轮廓和动作余量；按姿态设置关节与裁切 | 当前源图 `1122 × 1402`，代码以它建立逻辑坐标 |
| 表情 | 与人物同画布比例、缩放和位置；生成后叠图检查 | 当前也为 `1122 × 1402`，只局部取用眼嘴 |
| 鱼饰、飘带等装饰 | 真实透明背景，比例和固定点适合布局 | 当前鱼饰 `1536 × 1024`，飘带 `724 × 2172` |

这些是本版保留的素材规格，不是所有模板的固定标准。人物尺寸来自选定输出，随后成为绑定坐标基准；没有记录证明四张图的像素数都经过了预先的最优性能计算。

## 大小怎么选

以最大预期窗口下的**实际图片显示尺寸**为起点，考虑目标屏幕 DPR：

```text
源图尺寸的参考目标 ≈ 实际显示尺寸（CSS 像素）× DPR
```

保留适当余量，并在目标窗口看清晰度。`object-fit: contain` 的图片可能比容器小，应按实际绘制尺寸计算；大视口、窄屏和动作缩放都要考虑。DPR 表示物理像素与 CSS 像素的比例，见 [MDN 说明](https://developer.mozilla.org/en-US/docs/Web/API/Window/devicePixelRatio)。

源图像素与逻辑坐标可以不同：例如注册位置一致、同比例的更高清人物，可映射回原逻辑画布。需要更多细节时应准备有实际细节的源图；单纯放大旧 PNG 或增大绘制缓冲，不会自动补回原图细节。SVG 的坐标含义见 [viewBox 说明](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/viewBox)。

## 替换时重点检查

- 人物和表情是否对齐；不同姿态要重新设置关节与裁切，不能只换文件名。
- 透明边缘、固定点和动作余量是否合适；不要分别裁紧人物与表情而破坏对齐。
- 宽屏、窄屏和实际动作中是否清晰、无拉伸、错位或遮挡。
- 图片优化以实际效果和文件大小比较，避免为了缩小包体损伤主体画质。
- 保留原始输出、来源与编辑记录，发布时使用有权分发的素材。
