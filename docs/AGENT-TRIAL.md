# 独立智能体试用与反馈

创作 Skill 仍是实验性指引。以下试用检查的是“智能体能否依据仓库完成用户的个性化作品”，与默认宵宫插件的安装、浏览器测试和原生验收分开。普通安装不启动这些试用。

## 已发生的三轮试用

截至 2026-10-08，根据实际产物、制作记录与维护者反馈整理。目录名只用于区分试用作品，不代表三个公开版本；第二、三轮曾在同一个试用目录修改，不能仅凭目录名判断是哪一版。

| 轮次 | 试用对象与可识别画面 | 暴露的问题与结论 |
| --- | --- | --- |
| 第一次 DS | 试用目录名 `dsh-entrance`：代码画出的女仆半身人物，大扇形背景与波纹 | 代码拼画近似人形未达到角色素材要求；不可作为合格角色作品。保留“不得用现场代码拼画替代人物素材”的边界 |
| 第二次 DS | `zzz-entrance` 早期版：现成女仆立绘，深海、警示条纹、声呐元素 | 已转用现成人物素材，但设计过度依赖鲨鱼和配色线索。后续研究应深化已有方向，不因这次批评否定这些线索本身 |
| 第三次 DS | `zzz-entrance` 修订版：校服持糖立绘、夕阳方块城市、水面、左上布条与小挂牌 | 把指引中的假设偏好当成默认，沿用休息场景和文案；精细立绘与粗糙城市缺乏统一，人物空间关系和左上装饰语义不清。维护者反馈女仆、邦布及角色配色等联系未得到体现，并明确表示视觉不通过；不能因抠图或技术检查完成宣称作品完成 |

三轮均不能作为默认宵宫独立插件的原生验收报告。这里不补造缺失的提交哈希、工具版本、技术通过项或帧率数据；后续测试需绑定实际源码和产物。第三轮的用户否定也不能改写成“只待审美确认”。

## 根据试用修正了什么

- 删除艾莲“假设偏好放松”的完整示范场景及示例文案，防止特定答案成为默认；未指定偏好保持未指定。
- 缩短入口，保留任务目标、素材边界与关键接入信息。允许有依据的视觉联想，不要求每个物件都能查到官方出处，也不虚构官方事实。
- 用实际全图判断画风、空间和元素关系；研究充分、象征解释完整或检查表通过，均不能代替完成度。
- 女仆、邦布、配色等是本角色可探索的线索，不是所有作品的必选清单。用户明确要求的部分仍须实现。

以上是依据失败作出的文档修正，尚未证明修订后的指引已通过新一轮独立制作。

## 下一次怎样试用

在新的工作副本中，用仓库完整内容和本次用户要求启动；不要附带前轮成片、策划答案或私有历史聊天。已有参考图按真实任务输入提供，避免为了测试临时增加用户并未提出的偏好。

> 请阅读本仓库 SKILL.md，根据我提供的角色、素材和要求制作个人入场作品，保留分层登场与水波交接。使用你实际可用的能力，展示可复开的结果，记录已完成和未验证的检查。

记录仓库提交、模型/智能体、操作系统、可用工具和实际修改；保存能分辨版本的预览。关注是否尊重任务范围、是否把示例当作偏好、素材与整体完成度是否成立，以及遇到能力缺口时是否如实处理。不要只测计划回答；实际制作后再判断结果。

每轮使用独立目录和预览端口，验收结果绑定该轮产物。结束后停止试用服务，移出活跃工作目录和插件加载路径；必要失败证据可另存隔离归档，不作为下一轮输入或默认作品。不要把整份私人试用目录、聊天或未获分发权利的角色素材上传到公开仓库。

技术检查、浏览器行为、原生宿主观察、视觉判断与用户反馈分别写明。试用通过只支持当次任务和环境，尚未覆盖的角色或平台保持未测试。具体记录标准见 [验收标准](ACCEPTANCE.md)。
