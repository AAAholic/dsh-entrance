# 通用创作流程：从角色研究到场景与素材

将任务交给自己的智能体时，从仓库根目录 [SKILL.md](../SKILL.md) 开始。它规定结果、判断依据与能力缺口处理；具体找图、抠图、修边或生成方法由执行智能体根据实际可用工具选择。本文保留创作概览与原案例来路，不要求使用作者相同的工具。

完整主题创作先走 **角色研究 → 场景构思 → 定向找素材 → 素材验收 → 分层实现 → 预览迭代 → 验证交付**。如果用户只要求换色、抠图或修一处细节，就沿用已有方向完成该范围，不扩大成一轮角色研究。已有合格图片和明确构思时，补齐必要判断即可，不强制换图或重新生成。

## 先弄清要表现角色的哪一面

研究的目的，是找到能指导选图和场景的线索，而不是收集整本设定集。检查下列方面与本次目标的关系；不相关的简短标注即可，没有固定条目数量要求。

| 线索 | 要弄清的内容 | 如何影响创作 |
| --- | --- | --- |
| 外形标志 | 本次采用的造型、轮廓、服饰与不能改动的特征 | 图片辨识度、裁切范围、朝向、动作余量 |
| 性格与习惯 | 表情、做事方式、日常偏好；哪些有依据 | 姿态、活动、节奏和文案语气 |
| 身份、生活与阵营 | 职业/身份、常见生活场景、所属组织 | 场景材质、道具与环境线索 |
| 关系与作品世界 | 与谁/什么有已知联系，世界中的物件如何使用 | 配角是否有理由出现，避免凭外观捏造关系 |
| 用户喜欢哪一面 | 用户更在意的气质、造型或情境，以及明确排除项 | 从同一角色的多种可能中选定本次表达 |

把线索分为 **官方/用户设定、二创诠释、创作提案**：官方介绍或作品内容支持原作事实；OC 以用户提供的设定为准；二创作者的服装、性格演绎不能直接改写为官方设定；新场景和新台词必须标为自己的设计。保存能定位到相关内容的链接、作者/文件与简短说明，未知就写未知，不从配色、阵营或配队关系推导私人关系。

覆盖关键方面不等于必须知道一切。只有未决信息会明显改变选图、人物原貌或用户意图时，才补问关键问题；已有信息足够时，在授权范围内自主作出普通构图选择并继续。不要把每一步变成人工审批。

## 从线索提出场景，再决定找什么图

先比较少量有实质区别的方向，例如同一角色的“安静休息”与“工作迎客”：活动、空间、人物与观众的关系应不同，不能只是同一构图换两套颜色。每个方向用短句说明依据、主画面、所需素材和主要难点，然后选一个主主题，保留少量有用的辅线。若用户已选定方向，直接深化，不重开无关选项。

把设计选择落到制作条件：人物正在做什么决定姿态与表情；场景决定背景/前景和道具；视觉重点决定人物与标题位置、宽窄屏裁切；气质决定层次、配色、动作幅度和文字语气。保留公共入场分镜与水波交接，不等于保留示例的鱼、扇、飘带或祭典语汇，也不等于只改颜色和角色名。

随后按条件定向搜索，而非先搜到一张热门图再替它编故事。检索可组合角色/造型、活动/姿态、画风和素材用途；记录参考图与最终素材各自的来源。优先评估用户已有图，合格则围绕它完成设计。需要新素材时，比较辨识度、构图适配、完成度、可分层性和使用条件，不以排名或文件名替代看图。

素材可行性应反过来修正构思：例如合格半身图可促使调整标题和前景关系；局部动作缺少条件时，可以换素材或制作路线。不能为方便实现而降低角色完成度、堆特效掩盖失真，或悄悄取消用户明确要求。若关键素材仍不可得，说明具体缺口，继续不依赖它的策划和工程准备；占位只算布局原型。素材标准与能力缺口处理见 [素材规格](ASSET-SPEC.md)。

## 轻量策划卡

直接填下面的短条目即可，按需要合并；它是执行依据，不是新增审批表。

- **任务与边界：**角色/OC、用户偏好、已有素材、必须保留、允许改变、本轮交付。
- **关键线索与依据：**外形、性格/习惯、身份/生活、关系/世界；分别标明设定、二创或提案，附来源，未知项不补造。
- **场景方向：**少量不同候选及取舍；选定的主主题、辅线，主动舍弃什么及原因。
- **制作映射：**人物姿态/表情与所需素材；背景/前景/配角；宽窄屏主次和文字空间；动作与文案如何支持主题。
- **定向素材清单：**沿用哪些图、还缺什么、搜索条件、来源/使用依据与关键质量要求。
- **未决与验收：**会改变方向的关键问题、素材可行性反馈，以及需要观察的身份、构图、动作和宿主证据。

## 艾莲示例：以下是设计建议，不是官方场景或台词

官方角色介绍提到适时休息与棒棒糖，可作为构思线索，但不能仅据此把角色简化成几个装饰符号。[官方角色介绍](https://zenless.hoyoverse.com/en-us/character) 可定位到 Ellen Joe。

可比较“工作间隙的片刻休息”和“家政工作中的迎客”两个方向：前者偏放松、低密度和日常感，后者偏有秩序的环境、迎客关系与家政细节。这里假设用户偏好放松的一面，选前者为主；家政与邦布只作为可考虑的辅线，不必全部塞进画面。

| 设计选择 | 对素材与画面的要求 |
| --- | --- |
| 以休息感为主 | 定向寻找符合所选造型、姿态放松的高质量图片；已有合格图直接沿用，不强迫改成全身或挥手 |
| 环境辅助人物 | 可设计简洁休息角和少量糖果线索，材质/颜色从选定主图协调；它们是场景提案，不宣称为官方房间或固定道具配置 |
| 让欢迎感保持克制 | 主体和标题各有空间；沿用分层进入与水波退出，局部动作按实际素材制作；新写“先休息一下，再开始吧。”须标为创作文案，不能冒充原作台词 |

如选择家政方向，[官方 Butler 介绍](https://zenless.hoyoverse.com/en-us/news/123357) 支持其维多利亚家政背景与宴会/后勤职责，可据此考虑环境或配角。若采用鲨牙布，[HoYoWiki 条目](https://wiki.hoyolab.com/pc/zzz/entry/113?lang=zh-cn) 的配队信息不能证明它是艾莲的专属宠物；组合只能按实际依据说明，不能虚构所有权或亲密关系。

新增邦布等配角同样需要合格素材与来源，遵守[角色素材禁用代码拼画的边界](ASSET-SPEC.md)：不能以 SVG/CSS/Canvas 代码拼画代替配角素材，也不能把配角改称装饰来规避。

## 从策划走到交付

选定素材先单独验收，再接入静态构图；静态成立后添加分层登场、允许的局部动作与水波交接。看完整动态过程，检查宽窄窗口、遮挡、裁切和节奏；问题可以返回素材或构思阶段处理。具体接入见 [模板替换教程](TEMPLATE-GUIDE.md)，当前参考工程没有现成主题导入器或通用人物绑定。

退出、重播、焦点、构建与实际宿主检查按 [验收标准](ACCEPTANCE.md) 留证；技术通过与视觉合格分别记录。安装、公开发布和工具付费等按已有授权处理，制作流程本身不扩大授权。

## 这版是怎样走过来的

这份模板来自维护者与 Codex 的持续协作：维护者确定主题、比较候选并提出修改；Codex 协助找参考、整理设计、准备素材、实现动效和验证；image 图像工具用于生成、编辑与重绘。最终画面是在多轮筛选和预览中形成的。

最初先研究旧欢迎页与分层揭幕等案例，尝试人物前景提取和修补，再生成新的动态姿态、温暖挥手等候选。独立预览中比较过“烟火归家”和“漫画爆发”方向，最终选用更温暖的微笑挥手人物，并制作与主图对齐的局部表情。

之后又结合维护者提供的参考例图，提取/重绘鱼饰与飘带，综合折扇、底部水纹和烟花。再根据预览反馈，调整人物问候、飘带轻摆、烟花形态、鱼群节奏与水波退出，最后提取成独立插件。

这里的“抠图”包含不同方法：有前景透明提取，也有借助图像工具修补或重绘。最终人物和装饰用过参考式生成/编辑，不能称为原图无损抠图。记录中的参考图也实际传入过生成工具，并不只是用于人工观看。

## 与 Codex / image 协作时怎么提要求

每轮说清楚三件事就很有用：**想要什么感觉、哪些部分保留、这次只改哪些部分**。例如：“保留人物和退场，鱼饰缩小一点，飘带要像被风吹起，但不要挡住标题。”

生成或编辑素材时再补充画布、透明背景和图层边界，例如人物图不要连带文字、烟花和背景。是否允许补全或重绘服从用户意图，已有合格素材可直接使用。比较候选时写下选用原因；把素材放进动态预览后，再决定下一轮修改。质量标准见 [素材规格](ASSET-SPEC.md)，整体作品检查见 [验收标准](ACCEPTANCE.md)。

## 最少留下哪些记录

- 参考来源、提示词和原始输出。
- 选用版本及简短理由，后续修改记录。
- 对应预览和必要的验证结果；测试通过与视觉满意分别记录。
- 素材的使用依据和来源标识，保留原始 PNG 的 C2PA 记录。
