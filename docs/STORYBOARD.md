# 分镜与视觉节奏

这段入场的重点是让画面按层次建立，再由同一个水波过程交接到真实工作台。完成构图后停留等待用户；它不是自动消失的开屏广告。

## 设计时间与真实时间

主分镜使用 `0…2.4` 的设计时间。设置的展开时长为 `D` 秒时，播放期间使用：

```js
designTime = Math.min(2.4, elapsedSeconds * 2.4 / D)
```

这样整体变快或变慢时，各层仍保持先后关系。默认 `D = 3.2` 秒；等待用户的停留时间不计入 `D`，水波退出另有固定 `2.2` 秒时钟。

| 设计时间 | 默认实际时间（约） | 画面事件 |
| --- | --- | --- |
| 播放前 | 不固定 | 解码资源，以低透明度真实图层进行短暂预绘制 |
| `0–0.70` | `0–0.93 s` | 红屏、折扇、上方鱼饰、左侧飘带、底部波带铺开 |
| `0.48–1.38` | `0.64–1.84 s` | 人物从右侧进入，细微缩放后落位 |
| `1.05–1.65` | `1.40–2.20 s` | 欢迎文案和品牌字样建立视觉层级 |
| `1.00–2.35` | `1.33–3.13 s` | 一次带收放包络的手掌与小臂问候 |
| `1.36–1.82` | `1.81–2.43 s` | 一次闭眼关键画面叠化；不是持续眨眼循环 |
| 截止 `2.40` | 截止 `3.20 s` | 有限烟花散尽，主时间轴停止 |
| 完成后 | 等待用户 | 仅开启的飘带继续随风，鱼群沿弧线连续错峰跃水 |
| 用户点击或按键 | 另计 `2.20 s` | 水滴、三道波前与场景遮罩共同揭开工作台 |

表中的动作窗口是初始分镜基准。后续速度控制可以改变局部动作频率，但不应打乱人物落位与文案出现的整体关系。

## 构图不是元素平均分布

深青色背景承担安静的底色；朱红、旧金构成主要装饰色；人物和欢迎文案分别形成右、左视觉重点。烟花在装饰层之上、人物和标题之下，使人物自身遮住右侧火星。

折扇、红屏、底部波带应形成大块轮廓。细花枝、扇骨、同心弧纹只负责近看细节，不能把每个空处都填满。留白既要帮助阅读，也要避免出现没有关系的大块空洞。

底部波纹的丰富度来自多组错位圆心、不同弧数、深浅和遮挡关系。单纯把一组线画得更密，只会得到规则条纹。

鱼群在体型、身体/尾鳍轮廓、红金与青金配色、朝向、锚点和相位上有差别。每条鱼沿弧线跃过，起落留短水纹；跳跃窗口重叠，形成连续错峰节奏，不在水里水平来回游。数量与屏幕占用也要分开判断：代码里有三条鱼，并不代表日常画面能同时看见两三条。

## 烟花要在时间和形态上都有差异

初始烟花使用金菊、垂柳、双层牡丹、掌形、锦冠五种艺术化形态：

- 金菊以放射碎火星建立第一拍。
- 垂柳用较长尾迹和较强重力区分轮廓。
- 牡丹以双层星点构成较大的中心事件。
- 掌形用少数分叉方向，避免每簇都是整圆。
- 锦冠以不同拖尾长度和色彩收束。

它们沿微弯轨迹升起，不等间隔绽放；爆点分布在不同高度。确定性随机种子让每次预览可比较，而非每次都因随机布局改变审美判断。

## 角色微动

手掌围绕腕部转，小臂围绕肘部转，二者带少量相位差。基础包络为 `sin(πu)`，动作开始和结束均为零。原始基准的正弦系数为手腕 `3.3°`、小臂 `1.23°`；系数不是每帧的实际角度。

基础图、手臂、手掌使用重叠裁切，关节附近留余量。眼嘴只覆盖局部，表情图失效时保留基础脸。这样的微动是二维分层变换，不是完整骨骼、网格变形或 Live2D 绑定。

## 窄屏需要重新安排关系

竖屏下人物转入下方、标题放上方、折扇位置和红屏宽度变化，鱼群避开品牌与进入提示。不要把桌面构图整体缩小后称作响应式完成。至少分别检查普通宽屏、矮窗口和手机宽度。

## 替换成自己的风格

先固定时间结构，再换配色、静态装饰、角色和文案。人物图尺寸、关节枢轴和 SVG 裁切路径有对应关系；换成不同姿势时必须重新定位，不能只替换文件名。

如果暂时没有分层素材，先做无手部与表情动作的静态主体，保留入场分层和水波交接。分镜成立后再增加局部动作，更容易判断问题来自节奏还是素材。
