# Animation preview

`demo.gif` shows the actual plugin modules rendered in Chromium on the repository's local preview page. It includes the layered entrance, overlapping fish leaps, and the complete 2.2-second water-ripple exit into the example workspace. It contains no private DSH workspace or chat content.

The 720 × 450 preview is sampled at 10 frames per second for 8.1 seconds and encoded with Pillow using a shared 256-color palette. Identical frames are combined without changing the duration. The JavaScript animation clock is controlled for capture; the workspace's browser animation is aligned to the same exit timeline. This is a browser-rendered demonstration, not a native DSH screen recording or a native-performance benchmark.
