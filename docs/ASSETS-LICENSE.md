## 添加新素材时记录什么

为每个实际随包分发的图片/字体/音频记录：

| 字段 | 示例含义 |
| --- | --- |
| 文件 | 仓库相对路径与用途 |
| 来源 | 自绘、委托、生成流程或原始来源链接 |
| 作者/工具 | 实际作者、工具与必要署名 |
| 使用范围 | 明确的素材许可证或分发依据 |
| 修改 | 裁切、改色、分层等 |
| 排除内容 | 许可不覆盖的角色、标志、参考图片等 |

文件名、分辨率、SHA-256 可帮助追踪版本，但不能替代来源与使用范围。

## 替换角色时的技术要求

人物基准画布为 `1122 × 1402`。角色模块的腕部、肘部坐标和 SVG 裁切区以该画布为单位；表情图必须与基础图对齐。不同姿势需要同时调整裁切、枢轴、眼嘴区和无障碍名称。

飘带需要真实 alpha 通道，并在顶端留下合理固定点。鱼饰与角色以外装饰加载失败时，应降级为隐藏或静态，不能阻挡用户进入工作台。

## 公开文档与预览

公开截图使用演示工作台或无私人内容的页面。不要把原始聊天、账户余额、任务列表、绝对路径或个人配置作为验证附件上传。仓库的 `preview/index.html` 提供示例输入框与计数按钮；它使用实际随包 PNG，不包含用户的真实工作台资料。
